# Cafe Management Web App

A lightweight, fast, and secure cafe management system built for two users.

## Tech Stack

- **Frontend:** React 19 with JavaScript (JSX)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **Authentication:** Supabase Auth
- **Deployment:** Vercel

## Development Setup

### Prerequisites

- Node.js v24.22.0
- npm v12.2.0

### Available Scripts

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```
